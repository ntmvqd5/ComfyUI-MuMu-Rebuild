# ComfyUI-MuMu-Rebuild

木木系列节点（重制版）：ComfyUI 自定义节点插件。

## 安装（RH / ComfyUI 通用）

方式一（推荐，git clone）：

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/ntmvqd5/ComfyUI-MuMu-Rebuild.git
```

方式二（压缩包）：下载本仓库 ZIP，解压后把 `ComfyUI-MuMu-Rebuild` 文件夹放进 `ComfyUI/custom_nodes` 目录。

然后重启 ComfyUI（RH 后台重启工作流环境）即可。

> 注意：`nodes.py`、`safe_runtime.py`、`__init__.py` 三个文件必须放在同一目录，缺一不可。
